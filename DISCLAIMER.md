# Aviso

- Todo dado deste repositório é **100% sintético**, gerado por `synthetic-data/generate.py` com semente fixa.
  Nenhuma pessoa, empresa, número ou resultado é real. Os CPFs gerados são **inválidos de propósito** (dígito verificador errado).
- Empresas, sistemas, arquivos e métricas citados (por exemplo "Acme Retail") são **fictícios**.
- O conteúdo descreve **padrões técnicos genéricos** de engenharia de dados e de agentes de IA para People Analytics.
  Ele não reproduz código, regras de negócio, definições de indicadores nem documentação de nenhum empregador, atual ou anterior.
- Este repositório não representa a posição de nenhuma organização.
